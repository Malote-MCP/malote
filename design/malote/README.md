# Malote — proposta de logo v2

Proposta visual para o produto que conecta conversas e arquivos do WhatsApp a assistentes via MCP.

O símbolo explora um M construído com abas de envelope. A tipografia em minúsculas e as cores verde profundo, lima e branco acompanham a direção atual da landing page.

Arquivo: `logo-conceito-v2.png`. Prancha de exploração gerada com a ferramenta integrada image_gen; ainda não é um arquivo vetorial de produção. As aplicações na prancha apresentam pequenas variações de geometria que precisam ser unificadas na vetorização. A aplicação horizontal superior é usada no site e no aplicativo a partir de `apps/web/public/malote-brand.png`, preservando o arquivo fornecido e enquadrando a marca com um viewport SVG. Ainda é recomendável produzir um vetor final para a identidade.

## Prompt de geração

```text
Use case: logo-brand.
Create a polished logo proposal for Malote, a Brazilian software product that connects WhatsApp conversations and documents to AI assistants via MCP. Brand qualities: practical, thoughtful, confident, quiet, editorial.
Design ONE cohesive original identity. Symbol: bold geometric lowercase/uppercase M monogram constructed from two folded envelope flaps; two interlocking diagonal ribbon strokes imply messages travelling between two tools. Compact balanced square silhouette, distinctive negative space, few clean shapes, no thin details, recognizable at 24px. Do not draw a shopping bag, handbag, handle, briefcase, phone handset, bot or AI sparkle.
Wordmark exact text: "malote" in a refined contemporary lowercase sans serif, medium to semibold weight, generous deliberate optical kerning, friendly but precise. Main lockup symbol left, wordmark right.
Palette from existing website: deep forest teal #182e2d, warm off-white #fcfdf9, pale lime #d7f59a. Flat solid ink with no gradients, textures, shadows or 3D.
Deliver a beautifully restrained landscape presentation on off-white: large primary horizontal logo in the upper two thirds with generous whitespace; bottom row show same symbol alone as a deep teal square app icon with lime symbol, and same horizontal logo in off-white on a deep teal rectangular field. Do not add any captions, slogans, annotations or text beyond the exact wordmark. All three applications must use exactly the same symbol geometry. This is a considered professional software brand, not a generic stock icon.
```
